# Project Scope

## Objective
Design and implement a MySQL relational database for a guitar retailer.

## Functional scope
- Store product categories and catalogue records.
- Store customer and address records.
- Record orders, shipment dates and order line items.
- Query catalogue and order information.
- Produce basic aggregate reports.

## Technical scope
- MySQL 8.0 or later.
- Relational schema with primary keys, unique constraints and foreign keys.
- Indexes for common join and lookup columns.
- Reusable query and stored-procedure examples.
- Static documentation website deployable with GitHub Pages.

## Out of scope
The repository does not contain an application backend, live authentication, inventory transaction processing, payment processing or a production deployment of MySQL.
